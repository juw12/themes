Pull one into a project

A theme is eleven custom properties: seven colours, three font stacks and a corner radius. Drop the file in, write your CSS against var(--bg), var(--accent) and the rest, and the look follows.

theme.py is one file with no dependencies. It reads this folder first and falls back to GitHub.

How a theme gets in

  1. 93of my own repos scanned for the files that define a look: design notes, CSS, the main page.
  2. 67had a look of their own. The rest are scripts, data or research with no interface.
  3. 56live pages opened in a browser, light and dark, to read what is really painted.
  4. 56themes after projects that share one look were merged and private work was left out.
  • No colour is made up. Every value is in the project's CSS or on its page, or it is marked derived with the rule used.
  • Where the scan guessed wrong it was fixed by hand, and the reason is written on the card.
  • Contrast numbers are computed (WCAG 2 ratio), and anything under 4.5:1 for text is flagged, not hidden.
  • System fonts stay system fonts. Web fonts are named only when the project loads them.
