217 moving parts by React Bits, catalogued.

The second shelf. A theme is the paint; these are parts that move: text effects, cursors, cards, small controls and whole animated backgrounds. Each card says what the part does, what it needs, where to see it running, and the one line that puts it into an app.

React Bits is made by David Haz and is free to use in an app, also a paid one. Its licence (MIT + Commons Clause) does not allow handing the components on, so none of their code, sounds or demos is kept in this library. The install line pulls a part straight from reactbits.dev into your project.

Add one to a project

Pick the flavour your app is written in, press Copy install command on a card and run it in the project folder. It needs Node.js and works in any React or Next.js app.

theme.py does the same from a terminal, and can name a theme's colours to pass as props.
